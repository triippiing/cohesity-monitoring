# Dashboard design

The dashboards follow the StorSafe package exactly in style: a banner (logo, brand line, package version), full-width rounded pill section headers, and with the Business Text plugin every row of stat panels drawn as one card section, coloured by the same thresholds. Tables and charts are Grafana's own panels. Everything is generated by `tools/build-dashboards.py`; the colours come from the theme (`monitoring/theme.example.json`, or a site's `theme.json` through `Publish-CohesityDashboards.ps1`).

| Dashboard | Question it answers | Sections |
|---|---|---|
| Fleet | Is any cluster unhealthy, and which? | Estate cards (clusters, API down, failed checks, groups failing, SLA violations, critical alerts, nodes/disks out, collector age), one row per cluster, trends |
| Activity | What is running now, and what failed in the last day? | Now, backup runs in progress, runs per group in 24 h, last replication and archive per group, recoveries |
| Instance | Everything about one cluster | Health, capacity and storage domains, performance, protection groups and failed objects, nodes, sources/targets/licence, alerts, collector |
| Patch Management | Are the clusters on the same software and patch level, and are licences in date? | Versions, cluster table, applied patches, node software and hardware, licences |
| Alerts | What is the cluster telling us? | Open counts, new alerts per hour, newest open critical and warning alerts, counts by category and type |

Conventions:

- Every dashboard has the `cluster` variable (multi-select, All by default; single on Instance). A cluster name in any table links to its Instance page.
- Red means act (a failed run, a down API, a critical alert), orange means look (SLA miss, warning alert, paused group), blue is informational. Progress bars are blue; usage bars turn orange at 80 % and red at 90 %.
- Times in tables are absolute (`dateTimeAsIso`); ages and durations are in seconds with Grafana's units.
- Tables keep at most the latest value (instant queries); trends come from Prometheus history.
